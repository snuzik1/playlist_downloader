# PLDL — Playlist Downloader

![Windows 10/11](https://img.shields.io/badge/Windows-10%2F11-0078D6?logo=windows&logoColor=white)
![Python 3.10+](https://img.shields.io/badge/Python-3.10%2B-3776AB?logo=python&logoColor=white)
![License GPL-3.0](https://img.shields.io/badge/License-GPL--3.0-blue)

Настольное приложение для Windows: вставьте ссылку на плейлист, альбом,
трек или профиль исполнителя — получите папку с музыкой, тегами и обложками.

Это обычное окно программы, а не сайт в браузере: нет адресной строки и
вкладок. Всё работает локально, без облака и аккаунта в самом приложении.
Поддерживается Windows 10/11 x64.

## Скачать

Готовые сборки публикуются в разделе
[**Releases**](../../releases/latest) этого репозитория:

| Файл | Что это |
|---|---|
| `PLDL-Setup-<версия>.exe` | установщик для текущего пользователя: ярлыки, меню «Пуск», удаление |
| `PLDL.exe` | портативная версия одним файлом, без установки |
| `PLDL-Uninstall.exe` | отдельная утилита полного удаления приложения и его следов |
| `SHA256SUMS.txt` | контрольные суммы файлов релиза |

Проверить скачанный файл можно так:

```powershell
Get-FileHash .\PLDL-Setup-0.1.0.exe -Algorithm SHA256
```

Сверьте хэш со строкой в `SHA256SUMS.txt`. Файлы не подписаны цифровым
сертификатом, поэтому SmartScreen может показать предупреждение:
«Подробнее» → «Выполнить в любом случае». Исходники и сборочные скрипты
лежат в репозитории — при желании соберите всё самостоятельно (см. ниже).

## Быстрый старт (Windows)

1. Установите **FFmpeg**, если его ещё нет:
   ```powershell
   winget install Gyan.FFmpeg
   ```
2. Скачайте **`PLDL-Setup-<версия>.exe`** из раздела
   [**Releases**](../../releases/latest) и пройдите мастер установки.
   Права администратора не нужны. Установщик:
   - поставит приложение в `%LOCALAPPDATA%\Programs\PLDL`;
   - создаст ярлык **PLDL** на рабочем столе и в меню «Пуск»;
   - добавит удаление через меню «Пуск» и «Параметры → Приложения»;
   - проверит FFmpeg и подскажет команду, если его нет.
3. Запустите **PLDL** с рабочего стола. Вставьте ссылку, нажмите «Разобрать»,
   выберите треки и формат, затем «Скачать».

Готовый установщик публикуется в Releases. При локальной сборке
`build_installer.bat` кладёт его в корень как `PLDL-Setup.exe` и в
`dist\PLDL-Setup-<версия>.exe`. Эти файлы не коммитятся в git. Установщик
ставит приложение только для текущего пользователя, без UAC и записи
в Program Files.

Если установка не нужна, скачайте портативную версию **`PLDL.exe`** из
Releases. Это один файл: его можно перенести в любую папку, на рабочий стол
или на флешку. Python и библиотеки внутри — устанавливать их не нужно.
Первый запуск one-file exe может занять несколько секунд: программа
распаковывается во временную папку.

При первом запуске рядом с портативным `PLDL.exe` появятся:

- `settings.json` — настройки (создаётся при сохранении);
- `pldl.log` — журнал запуска и ошибок;
- `.cache` — служебный кэш yt-dlp.

Если папка с exe защищена от записи, настройки уйдут в
`%LOCALAPPDATA%\PLDL\`.

В установленной версии `settings.json`, `pldl.log` и `.cache` находятся
в `%LOCALAPPDATA%\Programs\PLDL\` — эта папка доступна на запись.

По умолчанию музыка сохраняется в `C:\Users\<Имя>\Music\PLDL`
(или в `Downloads\PLDL`, если папки `Music` нет). Папку можно изменить
в настройках.

> Для окна используется WebView2 — он уже есть в Windows 11 и в большинстве
> сборок Windows 10 вместе с Microsoft Edge. Если WebView2 недоступен,
> приложение автоматически откроет это же окно через установленный Edge
> или Chrome в режиме приложения, без вкладок и адресной строки.

## Установка и удаление

- Ярлыки на рабочем столе и в меню «Пуск» ведут на установленный
  `%LOCALAPPDATA%\Programs\PLDL\PLDL.exe`.
- Быстрое удаление: запустите **`PLDL-Uninstall.exe`** из Releases
  (или из локальной сборки). Он закроет PLDL, вызовет штатный
  деинсталлятор и доберёт остатки: ярлыки, настройки, журнал, кэш и запись
  в списке программ. Скачанная музыка не удаляется. Сам файл удалятора —
  отдельная утилита; он остаётся в папке, куда вы его сохранили.
- Штатное удаление: «Пуск» → PLDL → «Удалить PLDL» или
  «Параметры → Приложения → PLDL → Удалить». Папка установки удаляется
  вместе с `settings.json` и журналом; музыка в папке загрузки остаётся.
- Обновление: закройте PLDL и запустите новый
  `PLDL-Setup-<версия>.exe` поверх старой версии. Настройки и скачанная
  музыка при обновлении сохраняются.
- Портативную версию можно просто удалить вместе с её папкой.

## Запуск из исходников

Нужны **Windows 10/11 x64**, **Python 3.10+** и **FFmpeg**. Склонируйте
репозиторий или скачайте архив исходников со страницы Releases.

```powershell
winget install Python.Python.3.12
winget install Gyan.FFmpeg
```

При установке Python включите «Add Python to PATH». Затем:

1. `setup.bat` — создаст `.venv` и установит зависимости.
2. `run.bat` — откроет настольное окно приложения.

`run.bat` сам вызовет `setup.bat`, если окружение ещё не создано.

Веб-режим для отладки (открывается в браузере):

```powershell
.\.venv\Scripts\python.exe app.py
.\.venv\Scripts\python.exe app.py --port 9000 --no-browser
```

Настольный режим из терминала:

```powershell
.\.venv\Scripts\python.exe desktop.py
.\.venv\Scripts\python.exe desktop.py --browser   # окно Edge/Chrome вместо WebView2
.\.venv\Scripts\python.exe desktop.py --debug     # инструменты разработчика
```

Проверка без запуска окна:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m compileall -q app.py desktop.py pldl.py pldl tests
.\.venv\Scripts\python.exe pldl.py --help
```

## Сборка PLDL.exe

```powershell
build_exe.bat
```

Скрипт установит PyInstaller, соберёт one-file приложение и положит результат
в `dist\PLDL.exe`, а также обновит `PLDL.exe` в корне проекта. Сборка занимает
несколько минут и требует интернет для установки инструментов.

Иконка и параметры сборки лежат в `assets\pldl.ico` и `PLDL.spec`.
FFmpeg в exe не входит — он остаётся внешней программой. Артефакты
`PLDL.exe`, `PLDL-Setup*.exe`, `PLDL-Uninstall.exe` и папка `dist\`
не коммитятся в git; они публикуются в GitHub Releases.

## Сборка установщика

Один раз установите Inno Setup 6:

```powershell
winget install JRSoftware.InnoSetup
```

Затем запустите:

```bat
build_installer.bat
```

Скрипт заново соберёт `PLDL.exe`, скомпилирует `installer.iss` и положит
готовый установщик в корень как `PLDL-Setup.exe`, а версионную копию —
в `dist\PLDL-Setup-<версия>.exe`. Inno Setup ищется в `%LOCALAPPDATA%`,
`Program Files` и `Program Files (x86)`.

Установщик русскоязычный, ставится для текущего пользователя без прав
администратора. Он создаёт ярлыки на рабочем столе и в меню «Пуск»,
добавляет деинсталлятор и проверяет наличие FFmpeg. Оформление мастера
лежит в `assets\installer-large.bmp` и `assets\installer-small.bmp`.
Вместе с приложением устанавливаются `LICENSE`, `NOTICE` и
`THIRD_PARTY_NOTICES.md`.

Вместе с установщиком `build_installer.bat` пересобирает
`PLDL-Uninstall.exe`. Отдельно удалятор собирается так:

```bat
build_uninstaller.bat
```

Для этого нужен C#-компилятор из .NET Framework 4.x — он есть в Windows 10
и 11. Исходник удалятора лежит в `uninstaller\Program.cs`.

## CLI

CLI работает без окна и использует те же настройки:

```powershell
# скачать плейлист с настройками по умолчанию
.\.venv\Scripts\python.exe pldl.py "https://music.yandex.ru/users/.../playlists/123"

# только показать список треков
.\.venv\Scripts\python.exe pldl.py "URL" --list

# выбрать треки и формат
.\.venv\Scripts\python.exe pldl.py "URL" --select 1-10,15 --format m4a --quality 256

# сохранить параметры и открыть папку после загрузки
.\.venv\Scripts\python.exe pldl.py "URL" -o "D:\Music" --open --save-settings
```

Основные флаги:

| Флаг | Значение |
|---|---|
| `-o, --output` | папка загрузки |
| `-f, --format` | `mp3`, `m4a` или `original` |
| `-q, --quality` | битрейт: 320/192/128 для MP3, 256/128 для M4A |
| `-s, --select` | выбор треков: `1-5,8,12` |
| `-c, --concurrency` | одновременных загрузок, 1–6 |
| `--match-source` | `auto`, `youtube` или `soundcloud` |
| `--proxy` | HTTP/SOCKS-прокси |
| `--cookies` | браузер для cookies: `chrome`, `edge`, `firefox`… |
| `--ffmpeg` | путь к `ffmpeg.exe` |
| `--no-folder` | не создавать отдельную папку плейлиста |
| `--no-index` | не добавлять номера к именам файлов |
| `--list` | показать треки без загрузки |
| `--dry-run` | разобрать ссылку без загрузки |
| `--open` | открыть папку после загрузки |
| `--save-settings` | сохранить переданные параметры |

## Форматы

- **MP3** — 320, 192 или 128 kbps.
- **M4A** — 256 или 128 kbps (AAC).
- **Как есть** — без перекодирования, в исходном формате источника
  (например, Opus в `.webm`/`.opus`).

В файлы встраиваются исполнитель, название, альбом, номер трека, год
и обложка (если её удалось получить). Для MP3 используются ID3v2.3,
для M4A — MP4-теги.

## Что поддерживается

| Сервис | Ссылки | Как скачивается |
|---|---|---|
| Яндекс Музыка | плейлист, альбом, трек, исполнитель | метаданные напрямую, аудио — поиск на YouTube/SoundCloud |
| SoundCloud | сет, трек, профиль | напрямую через yt-dlp |
| Spotify | плейлист, альбом, трек, исполнитель | метаданные Spotify, аудио — поиск на YouTube/SoundCloud |
| VK Музыка | плейлист, профиль | через VK API (нужен токен с доступом к аудио) |
| Deezer | плейлист, альбом, трек, исполнитель | метаданные Deezer, аудио — поиск |
| YouTube / YouTube Music | плейлист, трек, канал | напрямую через yt-dlp |
| Bandcamp | альбом, трек | напрямую через yt-dlp |
| Другие сайты | всё, что умеет yt-dlp | напрямую |

### Как это работает

- **SoundCloud, YouTube, Bandcamp и другие сайты** скачиваются напрямую
  через yt-dlp — с прогрессом, возобновлением и обработкой плейлистов.
- **Яндекс Музыка, Spotify и Deezer** отдают только метаданные. Приложение
  находит каждый трек на YouTube или SoundCloud по исполнителю, названию
  и длительности, скачивает найденное и ставит теги из исходного каталога.
  Совпадение может быть неточным — проверяйте журнал задания.
- **VK Музыка** работает через официальный `api.vk.com`: приложение
  запрашивает плейлист и прямые ссылки на аудио, затем скачивает файлы.

## Папки и повторные запуски

Для каждого плейлиста создаётся отдельная папка, например:

```
D:\Music\PLDL\
  Мой плейлист\
    01. Исполнитель - Первый трек.mp3
    02. Исполнитель - Второй трек.mp3
    .pldl_manifest.json
```

- Номера добавляются, только если в плейлисте больше одного трека.
- Недопустимые символы Windows заменяются, длинные имена обрезаются,
  совпадения получают суффикс `(2)`, `(3)`.
- В папке плейлиста лежит скрытый `.pldl_manifest.json` — по нему
  приложение понимает, что уже скачано. При повторном запуске готовые
  треки пропускаются, ошибки можно повторить кнопкой «Повторить».
- Временные файлы складываются в `.pldl_tmp` внутри папки загрузки
  и удаляются после завершения.
- Отдельную папку и нумерацию можно отключить в настройках или флагами
  `--no-folder` / `--no-index`.

## Настройки

В интерфейсе (шестерёнка) можно задать:

- папку загрузки, формат и качество;
- отдельную папку для каждого плейлиста и нумерацию треков;
- сколько треков качать одновременно (по умолчанию 2, максимум 6);
- источник поиска: YouTube, SoundCloud или автоматически;
- прокси и cookies из браузера — помогают для YouTube, SoundCloud
  и закрытых ссылок;
- Client ID/Secret Spotify (необязательно);
- токен VK (для VK Музыки);
- путь к FFmpeg, если он не находится автоматически.

Настройки хранятся локально в `settings.json` рядом с exe (или в
`%LOCALAPPDATA%\PLDL\`, если папка защищена от записи). Токены и секреты
маскируются в интерфейсе и никуда не отправляются, кроме запросов
к соответствующим сервисам.

## VK

VK не отдаёт музыку без авторизации. В настройках есть поле «Токен VK»:
нужен пользовательский токен с доступом к аудио. Приложение обращается
к официальному `api.vk.com` и скачивает файлы по прямым ссылкам, которые
возвращает VK. Без токена VK-ссылки не обрабатываются.

Поддерживаются ссылки вида:

- `https://vk.com/music/playlist/{owner}_{album}`
- `https://vk.com/audio?z=audio_playlist{owner}_{album}`
- ссылки с `access_key` для закрытых плейлистов.

## Spotify, YouTube и SoundCloud

- **Spotify** официально не работает в РФ. Приложению нужен доступ к
  `open.spotify.com`/`api.spotify.com`: включите VPN/прокси (поле «Прокси»
  в настройках) или укажите свои Client ID/Secret. Ошибки `403`/`451`
  означают региональную блокировку, а не проблему с ссылкой.
- Аудио из Spotify не скачивается: приложение берёт только метаданные,
  а звук ищет на YouTube/SoundCloud.
- **YouTube** может попросить подтвердить, что вы не бот. Выберите браузер
  в «Cookies из браузера» (например, Chrome или Edge), закройте браузер
  и повторите. Для закрытых видео нужны cookies аккаунта с доступом.
- **SoundCloud** отдаёт треки напрямую; для Go+/приватных треков могут
  понадобиться cookies.

## FFmpeg

FFmpeg нужен для конвертации в MP3/M4A и встраивания обложек. Если
программа его не нашла, установите:

```powershell
winget install Gyan.FFmpeg
```

и перезапустите приложение. Либо укажите полный путь к `ffmpeg.exe`
в настройках. Без FFmpeg режим «Как есть» всё ещё работает, но MP3/M4A
конвертировать нельзя.

## Приватность и безопасность

- Приложение не слушает внешнюю сеть: встроенный сервер доступен только
  на `127.0.0.1` и нужен лишь для связи окна с логикой.
- POST-запросы защищены случайным токеном страницы, проверяются Host
  и Origin; включена CSP.
- Никакой телеметрии и облачной синхронизации. Наружу уходят только
  запросы к сервисам, ссылки на которые вы вставили (и к YouTube/
  SoundCloud для поиска аудио).
- Повторный запуск не создаёт второе окно: приложение найдёт уже
  запущенный экземпляр и выведет его на передний план.
- Не прикладывайте `settings.json`, `pldl.log`, cookies и токены к
  публичным issue. Перед публикацией журнала удалите секреты.

## Частые проблемы

- **Окно не открывается** — посмотрите `pldl.log` рядом с exe (у установленной
  версии — в `%LOCALAPPDATA%\Programs\PLDL\`). Если в нём ошибка WebView2,
  установите «Microsoft Edge WebView2 Runtime» или запустите `PLDL.exe --browser`.
- **Python не найден при запуске из исходников** — переустановите Python
  с включённым «Add Python to PATH» или запустите `py -3 setup.bat`.
- **`pip` долго ставит зависимости** — это нормально при первом запуске;
  нужен интернет.
- **YouTube просит подтвердить, что вы не бот** — см. раздел выше про cookies.
- **Spotify: 451/403** — нужен VPN/прокси или свои ключи Spotify API.
- **Не находится FFmpeg** — установите его или укажите путь в настройках.
- **Медленно** — треки ищутся по одному. Уменьшите количество
  одновременных загрузок, если ловите лимиты сервисов.
- **Порт занят** — приложение само выберет следующий свободный; для
  пользователя это незаметно.
- **SmartScreen не даёт запустить установщик** — файл не подписан цифровой
  подписью. Нажмите «Подробнее» → «Выполнить в любом случае» или соберите
  установщик самостоятельно через `build_installer.bat`.
- **Ярлык на рабочем столе не появился** — запустите установщик ещё раз
  и оставьте включённым пункт «Создать ярлык на рабочем столе».
- **Антивирус ругается на exe** — это типично для PyInstaller. Добавьте
  файл в исключения или соберите exe самостоятельно через `build_exe.bat`.

## Ограничения

- Скачивайте только тот контент, который имеете право скачивать,
  и соблюдайте условия сервисов. Это инструмент для личного использования.
- DRM-защищённые источники не поддерживаются.
- Поиск аудио для Яндекс Музыки/Spotify/Deezer — эвристика: возможны
  неверные совпадения или отсутствие трека на YouTube/SoundCloud.
- За один раз обрабатывается до 1000 треков по умолчанию (настраивается
  в `settings.json`, максимум 5000).

  Spotify, YouTube, VK, Яндекс Музыкой, Deezer, SoundCloud или Bandcamp.
